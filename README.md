# Веб-приложение управления предприятием

## Описание проекта

Данный проект представляет собой веб-приложение, разработанное на Java EE, предназначенное для управления предприятием. Приложение позволяет работать с заказами, пользователями и задачами в зависимости от роли пользователя.

## Цели проекта

- Изучение современных технологий веб-разработки
- Разработка полнофункционального веб-приложения
- Реализация архитектуры MVC
- Работа с базой данных
- Создание удобного пользовательского интерфейса

## Функциональность

### Заказчик
- Просмотр списка заказов
- Добавление новых заказов
- Удаление заказов
- Оплата заказов

### Менеджер
- Просмотр закрепленных работников
- Назначение работников на заказы

### Работник
- Просмотр назначенных заказов
- Отметка выполнения задач

## Используемые технологии

- **Java (OpenJDK 21)**
- **Java Servlet API**
- **JDBC**
- **MySQL**
- **Apache Tomcat**
- **Maven**
- **JSP**

## Архитектура

Приложение реализовано по шаблону **MVC (Model-View-Controller)**:

- **Model (Модель)** — классы сущностей и работа с БД
- **View (Представление)** — JSP-страницы
- **Controller (Контроллер)** — сервлеты
  
## Структура проекта

src/
- `Services/` # Бизнес-логика
- `Servlets/` # Контроллеры
- `Structure/` # Сущности (модель)

## Основные компоненты

### Сервлеты

- `LoginServlet` — авторизация и регистрация
- `CustomerServlet` — действия заказчика
- `ManagerServlet` — действия менеджера
- `WorkerServlet` — действия работника

### Фильтры

- `CodingFilter` — кодировка UTF-8
- `AuthFilter` — разграничение доступа
- `AccessFilter` — защита ресурсов

### Сервисы

- `ContractService`
- `DataBaseService`
- `HashService`
- `ItemService`
- `LoginService`
- `StringService`
- `TaskService`
- `UserService`

## Веб-страницы

### Аутентификация
- `/login/login.jsp` — вход
- `/login/auth.jsp` — регистрация

### Заказчик
- `/customer/main.jsp` — личный кабинет
- `/customer/add.jsp` — создание заказа

### Менеджер
- `/manager/main.jsp` — управление заказами

### Работник
- `/worker/main.jsp` — выполнение задач

### Ошибки
- `authError.jsp` — ошибка авторизации
- `accessError.jsp` — ошибка доступа
